# Keyboard controls

The presenter drives the whole experience from the keyboard. Nothing is visible
on screen during the presentation — no navigation, no progress bar, no cursor.

| Key | Action |
|---|---|
| `→` or `Page Down` | Advance to the next chapter |
| `←` or `Page Up` | Go back a chapter |
| `Space` | Play / pause the current cinematic sequence. On a chapter that has already settled, it replays that chapter from the start. |
| `1` – `7` | Jump straight to a chapter |
| `F` | Enter or leave fullscreen |
| `M` | Mute or unmute |
| `Esc` | Show or hide the presenter panel |
| `Enter` / `Space` | On the opening screen: begin |

## Behaviour worth knowing before presenting

- **Nothing ever auto-advances.** Every chapter plays its sequence once, settles
  into its hold composition, and waits. It will wait indefinitely.
- **Pausing is always available.** `Space` stops the sequence wherever it is;
  the composition holds exactly as it stands.
- **Audio only starts after `BEGIN`.** That gesture is what lets the browser
  enable sound. `M` mutes at any point, and audio failure never interrupts
  anything.
- **The cursor is hidden** while presenting, and returns whenever the presenter
  panel is open.
- **The presenter panel** (`Esc`) lists all seven chapters with a one-line note
  on what each is for, and flags anything still running on a placeholder.
- **Reduced motion** is respected: if the machine is set to reduce motion, every
  sequence is replaced by clean cuts and still compositions. The complete story
  and all copy are preserved.
